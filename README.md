TP1 — Paradigmas de Programación

Legajo: 53527  
Lenguaje: Java

------------------------

Encapsulamiento y Abstracción: Atributos privados, getters/setters y calificadores de acceso en las clases.
Relaciones entre Clases: Agregación con `Sala` y Composición con la lista de `Actividades`.
Herencia y Polimorfismo: Transformación de `Actividad` a clase abstracta para derivar en subclases específicas (`Charla` y `Taller`).

------------------------

Ejercicio 1: Implementé la clase base `EventoUniversitario` aislada, con sus constructores (incluyendo el de copia) y manejo de contadores de clase.

Ejercicio 2: Incorporé la estructura de relaciones agregando la clase `Sala`, `Actividad`, `Estudiante` e `Inscripcion`, permitiendo asociar estudiantes inscriptos a las actividades.

Ejercicio 3: Terminé el ejercicio aplicando herencia y polimorfismo. Hice `Actividad` abstracta e implementé `Charla` y `Taller` con cálculo de costos específicos e impuestos (21%).

Ejercicio 4: Elaboré el mapa de memoria (Stack vs Heap) correspondiente a la ejecución completa en la clase `App`.
